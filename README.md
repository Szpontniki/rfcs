## RFCs

This repository contains Szpontniki's **R**equest **F**or **C**omment discussions. If you're unfamiliar with the format please give this Wikipedia page a read: [RFC](https://en.wikipedia.org/wiki/Request_for_Comments).

### Why?

You'd be right to point out that our organization is of minuscule scale and introducing an RFC process may be overengineering it. To learn why we chose to do so please read [RFC 1](https://github.com/Szpontniki/rfcs/blob/master/rfcs/0001-rfc-process.md). Generally speaking, our focus was on creating a space dedicated towards tracking organization wide ideas, as we're working in a polyrepo environment and creating numerous GitHub issues across all of them, regarding the same topic, would've gotten messy quickly.

### Contributing

If you'd like to open an RFC please take a look at [CONTRIBUTING.md](./CONTRIBUTING.md). It will provide you with all the necessary context required to start a new discussion. Additionally, if you want to contribute towards the project as a whole, I encourage you to check out our [documentation](https://szpontniki.khenzii.dev/docs).
